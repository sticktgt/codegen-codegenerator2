# Architecture

The prototype has a React frontend and a Python backend with local JSON storage.

Frontend extension points:
- `frontend/src/screens/`
- `frontend/src/widgets/`
- `frontend/src/actions/`
- `frontend/src/routes/routeRegistry.js`

Backend extension points:
- `backend/app/api/`
- `backend/app/services/`
- `backend/app/models/`
- `backend/app/storage/`
- `backend/app/main.py`
